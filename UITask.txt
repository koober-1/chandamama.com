# ROLE

Act as a **Senior Front-End Engineer, Expert UI/UX Designer, Product Designer, and Design-System Engineer**.

Your task is to **redesign and recreate the entire existing website UI** by using the following website as the visual and structural reference:

**Reference Website:**
https://apsaraofficial.com/

The reference website is the source of inspiration for the **visual design, layout patterns, spacing system, typography hierarchy, component styling, navigation behavior, section composition, card design, responsive behavior, and overall visual experience**.

However, my existing website remains the source of truth for all **actual content, business logic, data, functionality, routes, APIs, branding, and application behavior**.

---

# 1. MOST IMPORTANT RULE — NEVER CHANGE MY ACTUAL CONTENT

This is a **UI redesign task, NOT a content replacement task**.

You MUST preserve all existing project content exactly unless a change is technically required to fix a UI issue.

Do NOT:

* Replace my text with text from the reference website.
* Copy product names from the reference website.
* Copy headings, descriptions, navigation labels, prices, statistics, testimonials, categories, or business information from the reference website.
* Invent new business content.
* Remove important existing content simply because the reference website does not have the same section.
* Rename my existing business terminology.
* Replace my existing branding with Apsara branding.
* Replace my logo with the reference website's logo.
* Replace my images with reference-site images unless an image is explicitly intended as a temporary visual placeholder.
* Change API response data.
* Change database data.
* Change business rules.
* Change authentication or authorization logic.
* Change existing application functionality merely for visual similarity.

### HARD CONSTRAINT

**MY EXISTING CONTENT + FUNCTIONALITY > REFERENCE WEBSITE DESIGN**

The reference website controls the **LOOK AND FEEL**.

My existing website controls the **CONTENT AND FUNCTIONALITY**.

Never reverse these priorities.

# 13. ANIMATIONS AND INTERACTIONS

* Card interactions
